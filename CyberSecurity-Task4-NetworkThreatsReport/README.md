# Network Security Threats Report

## OASIS INFOBYTE – Cyber Security Internship

This project explains the most common network security threats, their impact, and the preventive measures used to reduce cybersecurity risks.

To study common network security threats and understand how organizations can protect their systems against cyber attacks.

- Malware
- Phishing
- Denial of Service (DoS)
- Distributed Denial of Service (DDoS)
- Man-in-the-Middle (MITM)
- Password Attacks
- SQL Injection
- DNS Spoofing
- IP Spoofing
- Insider Threats
